계약서에 없던 관리비를 나중에 청구받았다면 바로 입금하지 말고, 계약서 문구와 관리비 명세를 먼저 맞춰봐야 합니다. 제가 이런 상황을 정리할 때의 기준은 간단합니다. "계약서에 있는 비용인지, 실제 사용료인지, 공용관리비인지, 임대인이 임의로 붙인 금액인지"를 나누는 것입니다.

특히 퇴거 후에 "그동안 관리비가 빠졌다"며 한 번에 청구하는 경우가 있습니다. 이때 말싸움으로 시작하면 증거가 남지 않습니다. 문자나 이메일로 근거 자료를 요청하고, 받은 자료를 기준으로 인정할 금액과 다툴 금액을 나누는 쪽이 낫습니다.

## 먼저 볼 문서 4개

| 문서                   | 확인할 내용                       | 왜 중요한가                                    |
| ---------------------- | --------------------------------- | ---------------------------------------------- |
| 임대차계약서           | 관리비 금액, 별도 부담 항목, 특약 | 가장 먼저 보는 기준                            |
| 중개대상물 확인·설명서 | 관리비 설명 여부                  | 공인중개사를 통한 계약이면 설명 내용 확인 가능 |
| 관리비 명세서          | 청구 항목, 기간, 산출 방식        | 실제 비용인지 임의 금액인지 구분               |
| 영수증·계좌이체 내역   | 이미 낸 금액                      | 중복 청구를 막는 자료                          |

계약서에 "관리비 월 5만 원"이라고만 적혀 있고 세부 항목이 없다면, 그 5만 원에 무엇이 포함되는지가 쟁점이 됩니다. 반대로 "전기, 수도, 가스는 실사용분 별도"라고 적혀 있다면 실제 사용량에 따른 청구는 다툼의 여지가 줄어듭니다.

## 비용 성격부터 나누기

관리비라는 이름이 붙었다고 전부 같은 비용은 아닙니다.

| 비용 종류   | 예시                         | 대응 기준                            |
| ----------- | ---------------------------- | ------------------------------------ |
| 개별 사용료 | 전기, 수도, 가스, 난방       | 사용량과 검침 기간 확인              |
| 공용관리비  | 청소, 경비, 승강기, 공용전기 | 관리규약이나 명세서 근거 확인        |
| 정액관리비  | 매월 고정 관리비             | 계약서와 광고·설명 내용 확인         |
| 수선비      | 보일러, 배관, 시설 고장      | 임차인 과실인지 노후인지 구분        |
| 기타 청구   | 인터넷, TV, 주차, 폐기물     | 계약서 특약 또는 실제 이용 여부 확인 |

제가 가장 자주 보는 문제는 정액관리비와 개별 사용료가 섞인 경우였습니다. 예를 들어 "관리비 8만 원"이라고 해놓고 나중에 인터넷, 수도, 공용전기까지 따로 청구하면 임차인은 당연히 헷갈립니다. 이때는 "관리비 8만 원에 포함된 항목과 별도 청구 항목을 구분한 명세를 보내달라"고 요청해야 합니다.

_계약서 문구와 청구 명세를 나란히 놓고 보면 다툴 항목이 빨리 보입니다._

## 집주인에게 보낼 요청 문장

처음 답장은 짧고 건조하게 쓰는 편이 좋습니다.

> 요청하신 관리비는 계약서에 명확히 기재된 항목인지 확인이 필요합니다. 청구 기간, 항목별 금액, 산출 근거, 이미 납부한 금액과의 정산 내역을 서면으로 보내주세요. 자료 확인 후 계약서상 부담 의무가 있는 금액은 정산하겠습니다.

이 문장의 포인트는 "안 내겠다"가 아니라 "근거를 확인한 뒤 정산하겠다"입니다. 이렇게 남겨두면 나중에 분쟁으로 가더라도 무조건 버틴 것이 아니라 확인을 요청했다는 기록이 됩니다.

## 바로 입금하면 불리한 경우

아래 상황에서는 입금 전에 근거 자료를 먼저 받아두는 것이 좋습니다.

- 계약서에 관리비 항목이 없는데 퇴거 후 한꺼번에 청구한 경우
- 이미 매달 정액관리비를 냈는데 같은 항목을 다시 청구한 경우
- 청구 기간이 입주 전 또는 퇴거 후 기간까지 포함된 경우
- 수선비를 관리비처럼 청구했는데 고장 원인이 불명확한 경우
- "다들 냈다"는 말만 있고 명세서나 영수증이 없는 경우

돈을 먼저 보내면 나중에 돌려받는 쪽으로 싸워야 합니다. 금액이 작으면 더 애매합니다. 그래서 처음부터 항목별로 인정할 금액과 보류할 금액을 나눠서 답하는 편이 실무적으로 낫습니다.

## 표로 정리하면 분쟁이 줄어듭니다

문자로 길게 싸우기보다 아래처럼 정리해서 보내면 상대도 답하기 쉬워집니다.

| 청구 항목 | 청구 금액 | 계약서 근거             | 내 판단             | 요청 자료              |
| --------- | --------- | ----------------------- | ------------------- | ---------------------- |
| 수도요금  | 00원      | 실사용분 별도           | 확인 후 납부 가능   | 검침 기간, 고지서      |
| 공용전기  | 00원      | 명시 없음               | 근거 필요           | 관리비 명세서          |
| 인터넷    | 00원      | 관리비 포함 여부 불명확 | 중복 여부 확인      | 계약서 특약, 납부 내역 |
| 수선비    | 00원      | 별도 조항 없음          | 과실 여부 확인 필요 | 수리 내역서, 사진      |

마크다운 표를 쓸 때는 구분 줄을 `| --- | --- | --- |`처럼 단순하게 맞추는 것이 안전합니다. `---:` 같은 정렬 문법을 섞거나 마지막 칸 수가 다르면 블로그 화면에서 깨져 보일 수 있습니다.

## 공식 기준에서 확인할 부분

국토교통부와 법무부는 전월세 계약 때 월 10만 원 이상 정액관리비의 부과 내역을 세분화해 표시하도록 주택임대차표준계약서 양식을 개선했습니다. 또 소규모 주택 관리비 투명화 방안에서는 전기료, 수도료, 가스 사용료, 난방비, 인터넷 사용료, TV 사용료, 기타 관리비처럼 항목별 표시를 강화하는 방향이 안내되었습니다.

다만 이 기준이 있다고 해서 모든 과거 청구가 자동으로 무효가 되는 것은 아닙니다. 실제 분쟁에서는 계약일, 계약서 문구, 설명 여부, 실제 사용 내역, 이미 납부한 금액이 함께 검토됩니다.

## 이의제기 순서

1. 계약서와 청구서를 비교합니다.
2. 집주인에게 항목별 명세와 산출 근거를 서면으로 요청합니다.
3. 인정 가능한 금액과 보류할 금액을 나눠 답합니다.
4. 관리사무소나 공인중개사가 있다면 발급 자료를 확인합니다.
5. 계속 다투면 주택임대차분쟁조정, 지자체 민원, 소비자 상담을 검토합니다.

공인중개사를 통해 계약했다면 중개대상물 확인·설명서도 꼭 확인하세요. 관리비 설명이 어떻게 되어 있었는지 남아 있을 수 있습니다.

_통화보다 문자, 이메일, 내용증명처럼 기록이 남는 방식이 분쟁 대응에 유리합니다._

## 내용증명을 보낼 때 넣을 내용

내용증명은 협박장이 아니라 정리문입니다. 감정적인 표현을 빼고 사실만 적어야 합니다.

| 항목      | 적을 내용                            |
| --------- | ------------------------------------ |
| 계약 정보 | 주소, 계약 기간, 임대인·임차인       |
| 청구 내용 | 청구받은 날짜, 금액, 항목            |
| 확인 요청 | 계약서 근거, 명세서, 영수증 요청     |
| 내 입장   | 근거 확인 전 전액 납부는 어렵다는 점 |
| 정산 의사 | 근거가 확인된 금액은 정산하겠다는 점 |
| 회신 기한 | 예: 7일 또는 10일 이내               |

금액이 크거나 보증금에서 공제하겠다는 말을 들었다면 내용증명 전에 무료 법률상담이나 주택임대차분쟁조정 안내를 받아보는 것이 좋습니다.

## 지금 바로 할 일

1. 계약서에서 관리비 문구와 특약을 사진으로 저장합니다.
2. 집주인에게 항목별 청구 근거를 문자로 요청합니다.
3. 이미 낸 관리비와 이번 청구 금액을 표로 나눠 중복 여부를 확인합니다.

마지막으로, 관리비 분쟁은 "누가 더 억울한가"보다 "어떤 항목을 누가 부담하기로 했는가"가 핵심입니다. 계약서, 명세서, 영수증, 문자 기록을 기준으로 정리하면 감정 싸움으로 번지는 것을 줄일 수 있습니다.
